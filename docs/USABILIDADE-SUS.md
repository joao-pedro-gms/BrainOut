# Questionário SUS — System Usability Scale (BrainOut)

> **Instrumento do questionário pós-tarefa** citado em
> `USABILIDADE.md:191-213` (Seção 1.7.5).
>
> - Aplicar ao **final da sessão**, depois de T1, T2 e T3, com cerca
>   de **5 min** (`USABILIDADE.md:191`).
> - Participante identificado(a) apenas pela sigla **`P1`–`P5`**.
> - As respostas vão para a planilha de cálculo da Seção 6.2 de
>   [`docs/USABILIDADE-ficha-observacao.md`](./USABILIDADE-ficha-observacao.md)
>   e para a tabela de métricas agregadas da **Parte 2** de
>   `USABILIDADE.md`.
>
> **Fonte:** BROOKE, J. *SUS: A "quick and dirty" usability scale*.
> In: JORDAN, P. W.; THOMAS, B.; WEERDMEESTER, B. A.;
> McCLELLAND, I. L. (Ed.). *Usability evaluation in industry*. London:
> Taylor & Francis, 1996. p. 189–194. Mesma atribuição já registrada
> no Apêndice B de `USABILIDADE.md`.

---

## 1. Como aplicar

1. Aplicar **após** as três tarefas, com o participante ainda
   presente e antes de encerrar a gravação de tela
   (`USABILIDADE.md:191-193`).
2. Ler os **10 itens na ordem original**, um a um, sem alterar a
   redação. A ordem é parte do instrumento: os itens positivos e
   negativos já vêm **mesclados** para reduzir o viés de aquiescência
   (`USABILIDADE.md:195-196`).
3. Para cada item, pedir a resposta em escala Likert de **5 pontos** e
   **preencher a caixa correspondente** na tabela da Seção 2. Não
   pedir ao participante que preencha sozinho — o mediador marca.
4. **Não explicar** o que cada item quer dizer, **não sugerir**
   resposta e **não reformular**. Se o participante pedir ajuda para
   entender um item, registrar a dúvida (ela vira achado de
   instrumentação) e repetir o item uma única vez.
5. Aplicar as **3 perguntas abertas** da Seção 3 ao final,
   transcrevendo a resposta **literalmente**.
6. Calcular a pontuação conforme a Seção 4 e registrar na planilha da
   ficha de observação.
7. Registrar **pontuação SUS de 0 a 100 por participante**; a média
   dos cinco vai para a tabela 2.2 de `USABILIDADE.md`.

> **Ressalva de medição.** O SUS mede a **percepção de usabilidade**,
> não a validade nem o tempo de execução. Uma pontuação alta com T2
> acima do alvo de 3 min é um resultado real e deve ser reportado como
> tal — não "corrigido" na redação.

## 2. Itens Likert — respondidos em voz alta

Escala de resposta de cada item:

| 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|
| Discordo **totalmente** | Discordo **em parte** | Neutro | Concordo **em parte** | Concordo **totalmente** |

> Um item **positivo** pontua alto quando o participante concorda; um
> item **negativo** pontua alto quando o participante **discorda**.
> Essa inversão é o que o cálculo da Seção 4 corrige. Item positivo =
> ímpar; item negativo = par.

### Bloco 1 — leitura

| # | Item | 1 | 2 | 3 | 4 | 5 |
|---|------|---|---|---|---|---|
| 1 | Eu acho que gostaria de usar este app com frequência. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 2 | Eu acho o app desnecessariamente complexo. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 3 | Eu acho o app fácil de usar. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 4 | Eu acho que precisaria de ajuda de alguém com conhecimentos técnicos para usar o app. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 5 | Eu acho que as funções do app estão bem integradas. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 6 | Eu acho que há muita inconsistência no app. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 7 | Eu imagino que a maioria das pessoas aprenderia a usar o app muito rapidamente. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 8 | Eu achei o app muito complicado de usar. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 9 | Eu me senti muito confiante ao usar o app. | ( ) | ( ) | ( ) | ( ) | ( ) |
| 10 | Eu precisei aprender muitas coisas antes de conseguir usar o app. | ( ) | ( ) | ( ) | ( ) | ( ) |

**Notas de aplicação dos itens:**

- **Item 1** (positivo) — recorrência de uso.
- **Item 2** (negativo) — complexidade percebida.
- **Item 3** (positivo) — facilidade percebida.
- **Item 4** (negativo) — necessidade de apoio técnico.
- **Item 5** (positivo) — integração entre funções.
- **Item 6** (negativo) — consistência.
- **Item 7** (positivo) — facilidade de aprendizado imaginada
  (curva de aprendizado).
- **Item 8** (negativo) — complexidade percebida (redundante com o 2
  por desenho do instrumento; **não eliminar nem corrigir**).
- **Item 9** (positivo) — confiança.
- **Item 10** (negativo) — quantidade de aprendizado prévio exigida.

> **Item 7 — formulação para leitura em voz alta:** "Eu imagino que a
> maioria das pessoas aprenderia a usar o app muito rapidamente."
> É o único item cujo sentido depende de uma inferência ("imagino
> que a maioria"), não de uma experiência própria. Se o participante
> hesitar nesse item, anotar a hesitação como observação — **não**
> traduzir o item para "você acha que é fácil de aprender?", que é um
> item diferente.

## 4. Cálculo da pontuação

Procedimento conforme `USABILIDADE.md:212-216`.

### 4.1 Passo 1 — converter as respostas

- Para cada item **ímpar** (1, 3, 5, 7, 9), **subtrair 1** da
  resposta.
- Para cada item **par** (2, 4, 6, 8, 10), **subtrair a resposta de
  5** (isto é, `5 − resposta`).

Cada valor convertido fica entre **0 e 4**.

### 4.2 Passo 2 — somar

Somar os **10** valores convertidos. A soma vai de **0 a 40**.

### 4.3 Passo 3 — multiplicar

Multiplicar a soma por **2,5**. O resultado vai de **0 a 100**.

**Fórmula:** `pontuação SUS = ( Σ itens ímpares (resposta − 1) + Σ itens pares (5 − resposta) ) × 2,5`

### 4.4 Passo 4 — interpretar

| Faixa | Leitura |
|-------|---------|
| **Acima de 68** | Acima da média. |
| **68 ou abaixo** | Na média ou abaixo. |
| **Abaixo de 50** | Problemas graves de usabilidade. |

### 4.5 Exemplo de cálculo

> Exemplo **hipotético**, para conferência do procedimento. **Não é
> resposta de participante** e **não deve ser transcrito** para a
> planilha da ficha de observação nem para a tabela 2.2 de
> `USABILIDADE.md`.

Respostas de exemplo: `1=4, 2=1, 3=5, 4=2, 5=4, 6=1, 7=5, 8=2, 9=4, 10=1`

| Item | Tipo | Resposta | Cálculo | Valor convertido |
|------|------|----------|---------|------------------|
| 1 | ímpar | 4 | 4 − 1 | 3 |
| 2 | par | 1 | 5 − 1 | 4 |
| 3 | ímpar | 5 | 5 − 1 | 4 |
| 4 | par | 2 | 5 − 2 | 3 |
| 5 | ímpar | 4 | 4 − 1 | 3 |
| 6 | par | 1 | 5 − 1 | 4 |
| 7 | ímpar | 5 | 5 − 1 | 4 |
| 8 | par | 2 | 5 − 2 | 3 |
| 9 | ímpar | 4 | 4 − 1 | 3 |
| 10 | par | 1 | 5 − 1 | 4 |

Soma = `3+4+4+3+3+4+4+3+3+4` = **35**
Pontuação = `35 × 2,5` = **87,5** → registra-se **87,5** (a escala é
contínua; não arredondar para inteiro antes de comparar com 68).

## Checklist do autor — antes de aplicar

- [ ] As 10 perguntas são lidas **na ordem original**, sem
      reordenação nem agrupamento de positivas e negativas.
- [ ] A escala é lida com **todas as cinco âncoras** nomeadas
      (1 = Discordo totalmente … 5 = Concordo totalmente), não
      apenas como "de 1 a 5".
- [ ] A pontuação é calculada pela **fórmula da Seção 4**, conferida
      item a item — não estimada.
- [ ] As 3 perguntas abertas foram **transcritas literalmente**.
- [ ] Nenhum campo foi preenchido com **nome, e-mail, telefone ou
      identificador** do participante — apenas a sigla `P1`–`P5`.
- [ ] A média foi registrada na tabela 2.2 de `USABILIDADE.md` e a
      coluna "Faixa" preenchida (acima da média / abaixo de 68 /
      abaixo de 50).
