BrainOut — Visão geral do protótipo

Galeria das oito telas do app em alta fidelidade, com a identidade Material 3 atual (claro/escuro). Cada célula mostra a tela real em miniatura; o link abre a página cheia.

Nota: este site é uma prévia visual. Autenticação, sincronização offline e notificações não são executadas aqui — os dados exibidos são de demonstração.

Fluxo de navegação

  1. Splash → Login (botão «Começar»).
  2. Login → Cadastro (link «Criar conta»).
  3. Cadastro → Login (link «Voltar ao login»).
  4. Login → Projetos (link «Explorar projetos»).
  5. Projetos → Detalhe do projeto (card).
  6. Barra inferior: Projetos · Tarefas · Painel · Configurações.
  7. Configurações → Login (linha «Sair»).

O protótipo apenas navega entre páginas: nenhuma senha é enviada, nenhum dado é persistido e nenhuma requisição de rede é feita.
